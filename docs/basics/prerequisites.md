# Prerequisites

## Hardware required

To complete all chapters in "Basics", you need the following items in addition. All of them are pretty cheap:

- An LED
- A 220-330 Ω resistor
- Jumper wires (M2M, M2F, F2F)
- A breadboard

## Prerequisite knowledge

### Setting up simple circuits using breadboard

If you do not know how to set up simple circuits using breadboards, check out [this short 3 minute YouTube video](https://youtu.be/NREtn59WPho?si=iTIbcCEUhiaf0Jek&t=49) (it's easier to learn this way). Skip if you already know how breadboards work.

### Version control using Git and GitHub

You might already know this. But if you do not, check out [this tutorial](https://www.freecodecamp.org/news/git-and-github-for-beginners/) to learn more.

If everything is set up, let's start!
