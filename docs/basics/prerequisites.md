# Prerequisites

Here are a few things you should know beforehand.

## Setting up simple circuits using breadboard

If you do not know how to set up simple circuits using breadboards, check out [this short 3 minute YouTube video](https://youtu.be/NREtn59WPho?si=iTIbcCEUhiaf0Jek&t=49) (it's easier to learn this way). Skip if you already know how breadboards work.

## Basic C porgramming

You need familiarity with only basic C syntax and programming concepts. You can use [this tutorial from W3Schools](https://www.w3schools.com/c/c_intro.php).

## Version control using Git and GitHub

Check out [this tutorial](https://www.freecodecamp.org/news/git-and-github-for-beginners/) to learn Git & GitHub. Skip it if you are already familiar.

If everything is set up, let's start!
