# Shopping list

To complete all chapters in "Basics", you need the following items in addition:

- An LED
- A 220-330 Ω resistor
- Jumper wires (M2M, M2F, F2F)
- A breadboard (optional, but recommended)

All of them are very cheap. If you do not know how to set up simple circuits using breadboards, check out [this short 3 minute YouTube video](https://youtu.be/NREtn59WPho?si=ciHNzKcRCR766ekS) (it's easier to learn this way). Skip if you already know how breadboards work.

If everything is set up, let's start!
